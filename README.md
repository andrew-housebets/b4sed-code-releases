# B4SED Code releases

This repository holds signed and notarized release builds of the B4SED Code desktop app for macOS (Apple Silicon), along with the update manifests the app reads to update itself.

It contains no source code. Each GitHub Release here carries the `.dmg` installer, the `.zip` update payload, their `.blockmap` files and `latest-mac.yml`.

To install, download the `.dmg` from the latest release and drag B4SED Code to Applications. After that, the app updates itself from this repository.
